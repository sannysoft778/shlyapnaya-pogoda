# Шляпная погода — остров четырёх сезонов

Отдельное направление, старый сайт не меняется.

Маршрут: зима на снежной вершине → осень во внутренней долине → летнее озеро → весенний сад сакуры → зимняя вершина.
На станциях шляпы слегка покачиваются без вращения. Перелёты целой сцены, смена климата по пути. Обратный путь требуется, способ воспроизведения ещё согласуется: реверс всего видео обращает снег и листья.

Роли: Codex — ключевые изображения встроенным Imagegen; Claude — промпты и техническая схема. Платные генерации видео не запускать без отдельного решения пользователя.

Четыре supplied reference PNG сохранены рядом. Winter: сохранить вязаную форму/три цветка/листья, только холодная палитра; осень: camel felt cloche с коротким бантом; лето: соломенная с органзой без модели; весна: синяя тканевая с принтом и бантом.
