# Шляпная погода

Интерактивное путешествие по четырём сезонам единого горного острова.

Маршрут: снежная вершина → осенняя долина → летнее озеро → весенний сад сакуры → вершина.

В каждой точке шляпа слегка парит над естественной поверхностью без вращения. Переход между точками задуман как перелёт камеры со сменой климата.

Проект находится на этапе подготовки четырёх фотореалистичных ключевых изображений. Движение только вперёд по кругу. Точная механика запуска перелётов ещё обсуждается. Готов статичный веб-макет с переключением сезонов; видео пока не создано.

Исходные товарные фотографии используются локально как референсы; сторонние исходники и материалы не входят в публикацию.


Текущая версия изображений: `assets/keyframes/*-v5.png`. Шляпы расположены справа, слева оставлено место для текстовых плашек. Фактический размер — 1672×941; это ниже запрошенного 2K. Изображения созданы встроенным Imagegen и требуют утверждения перед производством видео. Промпты сохранены в `assets/keyframes/generation-v5.json`.

Локальный просмотр: из каталога проекта запустите любой статический HTTP-сервер и откройте index.html. В текущем сеансе доступен http://127.0.0.1:4232/. Оформление и выполненные проверки описаны в DESIGN.md.
