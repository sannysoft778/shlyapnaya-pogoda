# Шляпная погода

Интерактивное путешествие по четырём сезонам единого горного острова.

Маршрут: снежная вершина → осенняя долина → летнее озеро → весенний сад сакуры → вершина.

В каждой точке шляпа слегка парит над каменным подиумом без вращения. Переход между точками задуман как перелёт камеры со сменой климата.

Проект находится на этапе подготовки четырёх фотореалистичных ключевых изображений. Механика прямого и обратного перехода ещё обсуждается. Видео и веб-реализация пока не созданы.

Исходные товарные фотографии используются локально как референсы; сторонние исходники и материалы не входят в публикацию.
