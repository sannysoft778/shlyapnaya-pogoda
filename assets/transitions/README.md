# Пробный перелёт

Один экспериментальный клип «зима → осень» создан Kling 4.0 из двух утверждённых изображений. Перед запуском сервер оценил стоимость в 4 кредита. Он включён только в `pilot.html`; основная страница остаётся на фотографиях.

Исходный видеопоток: 1916×1080, 24 кадра/с, 97 кадров (4,04 с). Файлы для сайта перекодированы локальным FFmpeg в H.264 с отдельным ключевым кадром на каждом кадре и faststart для быстрой перемотки. В них нет аудиопотока. Версия 1080p — 1920×1080; версия QHD — 2560×1440, выбрана в манифесте пилота.

QHD получено обычным Lanczos-масштабированием без облачных кредитов. Дополнительная исходная детализация не создавалась; AI-апскейл не применялся.

`../audio/flight-air.mp3` — разрешённая пользователем дорожка `wind.mp3` из его локального островного референса. Она звучит отдельно и включается только по нажатию пользователя, затихает при остановке камеры. Код и остальные материалы исходного сайта не переносились.

Это тест механики и первого видеоклипа. Генеративное происхождение и ограничения не скрываются; одобрение всего сезонного маршрута из одного клипа не следует.

Следующий клип «осень → лето» создан отдельно: `autumn-summer-1080p.mp4` и `autumn-summer-1440p.mp4`, подробности и концептуальные кадры в `autumn-summer/`. К существующему плееру он пока не подключён; состояние следующих связок описано ниже.

Полные оригиналы всех завершённых генераций, включая отклонённые попытки, сохранены в masters/; контрольные суммы — masters/sha256.json.

Связка «лето → весна» собрана отдельно из двух 3-секундных отрезков с общим полностью хвойным кадром: summer-spring-1080p.mp4 и summer-spring-1440p.mp4. Фактическая длительность 6,04 с,145 кадров при 24 кадрах/с. Детали, промпты и результаты просмотра — summer-spring/. Новая связка к плееру не подключена.

Новая режиссура от 25.10.2026: [«зима → осень»](winter-autumn-dynamic/README.md) и [«весна → зима»](spring-winter-dynamic/README.md) переделаны как динамичные пролёты над склоном, без туманной заливки. В каждой папке — четыре концептуальных изображения, сценарий, фактические промпты, контрольные суммы и независимая оценка. Ориентир — 8 секунд на маршрут; крупная каменная поверхность скрывает смену локации только на коротком стыке около 0,2 секунды. На этапе раскадровок видеогенерация была отложена пользователем, кредиты Higgsfield не тратились. Зимне-осенняя переделка пока остаётся раскадровкой; весенне-зимний ролик создан следующим этапом 26.10.2026, подробности ниже. Нынешний зимне-осенний пилот — сохранённая старая версия до будущей замены.

«Весна → зима»: [1080p](spring-winter-1080p.mp4) / [1440p](spring-winter-1440p.mp4), 7,33 с, 176 кадров при 24 кадрах/с, без аудиопотока. Два исходных ролика по 4 с — по одной генерации каждого, общий расход 8 кредитов. Каменный проход ускорен локально, без новых облачных генераций; последующий подлёт сохранён. Полные оригиналы архивированы в masters/ и проверены SHA256. Сценарий, фактические промпты и ограничения — [spring-winter-dynamic](spring-winter-dynamic/README.md).

Отдельная проверка новой связки доступна в `../../pilot-spring-winter.html`, манифест — `spring-winter-clip.json`. Общий плеер выбирает маршрут через `data-flight`, поэтому исходный зимне-осенний пилот не заменён. В браузере проверены остановка после колеса, продолжение с той же позиции, завершение на зимней фотографии, повтор со старта и явное включение/выключение отдельного воздуха. На 390×844 видео не запрашивается и показывается зимняя фотография; телефонный кроп ролика остаётся неподтверждённым. Проверки управления и аудио входят в `node --test`. Слуховая оценка дорожки не выполнена автоматической проверкой.
