# Исходные видео

Полные исходные MP4 обеих завершённых генераций Higgsfield сохранены локально в проекте и в Git. Их SHA256 совпадает с первоначально скачанными файлами. Удаление генерации в сервисе не затрагивает эти файлы.

- `winter-autumn-source.mp4` — исходная связка зима → осень, 8 947 468 байт.
- `autumn-summer-source.mp4` — исходная связка осень → лето, 16 110 156 байт.

Здесь сохранены исходные аудиопотоки и метаданные генератора. Бесшумные версии для сайта и локально масштабированные QHD лежат уровнем выше. После каждой будущей видеогенерации следует сохранять исходный MP4 до очистки материала в Higgsfield; одних внешних ссылок недостаточно для архива.
