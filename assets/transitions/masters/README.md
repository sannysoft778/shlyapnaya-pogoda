# Исходные видео

Полные исходные MP4 завершённых генераций Higgsfield сохранены в проекте и Git. SHA256 совпадает с первоначально скачанными файлами. Удаление генераций в сервисе не затрагивает эти самостоятельные файлы. Контрольные суммы и размеры — sha256.json.

- autumn-summer-source.mp4 — 16 110 156 байт.
- summer-spring-attempt-01-source.mp4 — 21 029 831 байт.
- summer-spring-attempt-02-source.mp4 — 19 466 345 байт.
- summer-spring-part-01-source.mp4 — 10 637 407 байт.
- summer-spring-part-02-source.mp4 — 8 116 732 байт.
- winter-autumn-source.mp4 — 8 947 468 байт.

summer-spring-attempt-01/02 — отклонённые восьмисекундные варианты. summer-spring-part-01/02 — два исходных отрезка выбранной сборки.

Здесь сохранены исходные аудиопотоки и метаданные генератора. Бесшумные версии для сайта и локально масштабированные QHD лежат уровнем выше. После каждой будущей генерации исходный MP4 следует сохранять до очистки материала в Higgsfield; одной внешней ссылки недостаточно.
