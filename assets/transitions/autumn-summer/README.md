# Осень → лето

Три промежуточных изображения `*-v2.png` созданы встроенным Imagegen как режиссёрская раскадровка. По замечанию о реализме ослаблены оранжевый цвет, HDR-контраст и искусственный рельеф коры; уточнены блики и мелкие фактуры у озера. Это концептуальные кадры, а не извлечённые стоп-кадры готового ролика.

Одна генерация Kling 4.0, 1080p, 6 секунд, предзапускная оценка 6 кредитов. Начало — утверждённый `autumn-v6.png`, конец — `summer-v7.png`. Промежуточные изображения переданы в запрос в порядке лес → близкий ствол → летний берег.

Готовые файлы: `../autumn-summer-1080p.mp4` и `../autumn-summer-1440p.mp4`. Исходный видеопоток 1916×1080, 24 кадра/с, 145 кадров (6,04 с). Локальное перекодирование H.264 с независимыми кадрами и faststart подготовлено для последующего управления колесом. В этих файлах нет аудиопотока. QHD 2560×1440 — обычное Lanczos-масштабирование без дополнительных облачных кредитов, не нативная новая детализация.

Независимый покадровый просмотр: полёт через осенний лес читается по параллаксу, явных деформаций шляп, плавления дерева или растворения сцен не обнаружено. Смена места скрыта движущимся краем непрозрачного ствола. За ним открываются солнечное озеро, песок и летняя шляпа. Отдельного прохода по зелёному летнему лесу модель не сделала — камера выходит сразу на берег. Кадры движения отличаются от концептуальной раскадровки.

Видео сохранено отдельным материалом для просмотра. Утверждённый зимне-осенний клип, его плеер и основной сайт не менялись. Маршрут, короткие формулировки промптов и результаты проверки — в `storyboard.json`.
