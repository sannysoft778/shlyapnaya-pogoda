# Текущее решение

Обновлено 23 октября 2026.

- Маршрут только вперёд по кругу: зима → осень → лето → весна → зима. Обратные ролики не нужны.
- Версия изображений v1 отклонена по композиции и избыточной повторяющейся фактуре.
- Версия v2 создаётся с нуля по исходным товарным фото: шляпы справа, спокойная левая зона под будущие текстовые плашки Claude.
- На воде убрать рябь и блики; в окружении избегать тайлинга, одинаковых кустов и чрезмерной микрорезкости. Сохранить настоящую вязку, солому и принт изделий.
- Использовать только встроенный Imagegen. Платные операции Higgsfield/Polza, видео и переделка сайта не запущены.
- Запрошено 2048×1152; фактический размер проверяется отдельно. У версии v1 он 1672×941, поэтому она не считается нативным 2K.
- География и сохранность товара требуют визуальной приёмки. Отдельные генерации не гарантируют точное совпадение рельефа.
- Способ запуска перелёта (клик/колесо и поведение во время перехода) ещё обсуждается.
- Использование ключевого кадра на границах роликов помогает согласованию, но не гарантирует пиксельного совпадения. Стыки проверяются после генерации.

Этот файл уточняет прежний локальный план Claude. Исходные товарные фото и служебные ответы не публикуются.
