# Текущее решение — v5

Шляпы справа, слева место под текстовые плашки. Без подиумов: все шляпы парят над естественной поверхностью.

Шляпы нового дизайна по мотивам референсов, без точного копирования. Осенняя — кирпично-красная. Летняя — светлая соломенная с льняной лентой, на песчаном берегу. Озеро видно только летом. Весна прохладная, с сакурой и туманной долиной. Зима холодная, облачная, с лёгким снегом.

Приоритеты: согласованный свет предмета и окружения, объём, несколько планов глубины, естественная фактура без тайлинга и цифровых пятен. Утверждённые пользователем ракурсы сохранены.

Текущие файлы: assets/keyframes/*-v5.png. Фактический размер каждого 1672×941. Созданы встроенным Imagegen; фотографии не являются реальной предметной съёмкой. Полная географическая идентичность разных генераций не гарантирована.

Маршрут только вперёд: зима → осень → лето → весна → зима. Способ запуска перелётов ещё обсуждается. Подготовлен статичный макет с типографикой по примеру острова и круговым переключением сезонов. Видео и платные генерации не запущены. v2 и промежуточные версии не считаются утверждённым итогом.
